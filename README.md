# React POC - Hello World

A simple Hello World proof of concept built with React.

## Run in GitHub Codespaces

1. Open the repository in GitHub Codespaces.
2. Wait for the Codespace to finish installing dependencies.
3. Run:

```bash
npm start
```

The React development server runs on port 3000. Codespaces will forward the port and open the application in your browser.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
